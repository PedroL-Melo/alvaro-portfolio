# Portfólio Pessoal - Pedro Lucas 🚀

Bem-vindo ao meu portfólio pessoal! Este projeto foi desenvolvido **100% utilizando Inteligência Artificial (Google Gemini via Antigravity)** como parte de um desafio acadêmico proposto pelo professor Alvaro.

🔗 **[Acessar o Portfólio Online](https://PedroL-Melo.github.io/alvaro-portfolio/)**

## 🎯 Sobre o Projeto
O objetivo deste projeto foi explorar o potencial das IAs na construção de software, guiando a criação de um site completo de ponta a ponta sem a escrita manual de código por parte do desenvolvedor. A IA foi responsável por estruturar a arquitetura, escrever o HTML semântico, estilizar via CSS (com design moderno e glassmorphism) e aplicar a interatividade com JavaScript.

## ✨ Funcionalidades
- **Design Moderno:** Tema escuro (Dark Theme) com toques de cor indigo, garantindo uma leitura confortável e aspecto elegante.
- **Responsividade:** O layout se adapta perfeitamente a diferentes tamanhos de tela (computadores, tablets e celulares).
- **Animações Suaves:** Uso de Intersection Observers para criar efeitos de "fade in" nos elementos conforme o usuário rola a página.
- **Seções Dedicadas:**
  - **Sobre Mim:** Detalhamento da minha stack de tecnologias (Python, PHP, Node.js, C, IA, etc).
  - **Meus Projetos:** Demonstração de 6 projetos reais na área de desenvolvimento e Inteligência Artificial.
  - **Publicações:** Destaque para artigos científicos, como o sistema de automação MARIOT (WCAMA 2025).

## 🛠️ Tecnologias Utilizadas
Apesar de ter sido gerado por IA, a stack por baixo dos panos utiliza as bases essenciais da web:
* **HTML5:** Semântica e estrutura.
* **CSS3:** Variáveis nativas, flexbox, grid e glassmorphism.
* **JavaScript (ES6+):** Interatividade do lado do cliente (Vanilla JS).
* **Git & GitHub Pages:** Versionamento e hospedagem gratuita.

## ⚙️ Como executar localmente
Se desejar rodar o projeto em sua máquina:
1. Clone este repositório:
   ```bash
   git clone https://github.com/PedroL-Melo/alvaro-portfolio.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd alvaro-portfolio
   ```
3. Dê um duplo clique no arquivo `index.html` para abri-lo no seu navegador. Nenhuma instalação ou build é necessária.
